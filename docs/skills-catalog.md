# Skills catalog

Twenty-three skills. `jev-router` is the decision layer; the rest are the
library it learns to route between.

| Skill | What it does |
|---|---|
| `jev-router` | Route agent decisions through TypeSafe Jev: typed Choice/Score/Boolean evaluations with probabilities, plus a shadow-mode usage router that gates expensive actions. |
| `artifact-craft` | Quality bar for interactive web artifacts and dashboards: information hierarchy, chart selection, interactivity, mobile behavior, accessibility, performance, pre-ship checklist. |
| `artifacts-builder` | Design and build interactive frontend web artifacts, HTML dashboards, and UI components. |
| `bullshit-detector` | Score claims against a rubric: ingestion, analysis, and publishing pipeline for claim verification. |
| `canvas-design` | Create posters, visual art, and static designs in PNG and PDF, with bundled open-licensed fonts. |
| `cloudflare` | Work with Cloudflare: Pages deploys and the provider API. |
| `crowdcast` | Run multi-agent social simulations for prediction and creative exploration. |
| `delta-watch` | Structured strategic-intelligence briefing workflow: graded sources, dual confidence, templated briefs. Configure it for your own region and sources. |
| `docx` | Create, read, edit, and manipulate Word documents: tracked changes, comments, templates, charts. |
| `frontend-design` | Aesthetic direction for new UI: typography, layout, and choices that avoid templated defaults. |
| `invoice-organizer` | Sort messy invoices and receipts into a consistent, tax-ready folder structure. |
| `kinetic-typography` | Variable-font animation, split-text reveals, text-as-image effects, scroll-driven text motion. |
| `map-ranking-systems` | Research and model ranking, recommendation, and moderation systems with evidence tiers and calibrated confidence. |
| `pdf` | Read, extract, merge, split, watermark, fill, and OCR PDF files. |
| `pptx` | Create and edit PowerPoint decks: slides, charts, themes, speaker notes. |
| `satori` | A clinically informed companion for working through difficult questions: emotions, meaning, decisions. |
| `scroll-driven-storytelling` | Build scrollytelling pages: scroll-driven animation, sticky card stacks, parallax, reduced-motion fallbacks. |
| `self-audit` | Answer questions about your own agent's capabilities and data access by checking external sources instead of introspecting. |
| `stealth-browser` | Browser bot-detection literacy: how detectors fingerprint automation and how to behave like a real user. For legitimate automation hardening. |
| `superhumanizer` | Strip AI writing tells from text and rewrite it in a natural human voice; supports named tone-of-voice profiles. |
| `theme-factory` | Style artifacts with a theme: ten preset themes plus on-the-fly generation. |
| `tweet-forge` | Draft X/Twitter posts from a finding plus its numbers in a configured analyst voice, every draft verified at 280 characters or under. Fill in `config/` first. |
| `xlsx` | Open, read, edit, fix, and create spreadsheets; convert between tabular formats. |

Excluded from this repo: `newsroom-admin`, which was bound to a specific
site and credential workflow and could not be genericized. See
`docs/sanitization-notes.md`.
