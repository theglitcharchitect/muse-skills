# Source grading and triangulation

## Grades
- **A, primary/official.** Government data, central-bank releases, official statements and transcripts, treaties, court filings, gazette notifications, company/exchange filings.
- **B, credible secondary.** Established wire services, named-author think-tank or journal pieces with visible methodology, on-record trade-press reporting.
- **C, weak.** Single-source, visibly partisan, local press without independent verification, anonymous "officials say" with no named institution.
- **D, raw.** Rumor, unverified OSINT, anonymous or leaked material, hostile information-space claims. Lead paragraphs only, never load-bearing for a BLUF line or a forecast.

## Independence test
Two sources are not independent if they share one upstream origin: two outlets citing the same leak, the same wire feed, or the same unnamed official is one source wearing two mastheads. Independence requires separate original reporting chains. State explicitly when you cannot establish this.

## Triangulation floor
Any conclusion-driving claim needs 2+ genuinely independent A-B sources, or one A grade with an explicit single-source flag written into the line itself.

## Local-language and geographic diversity
Actively pull Bangla-language and multi-country-of-origin sources through CELL-LOCAL. Three Anglophone wires agreeing is a bias signal to interrogate, not a triangulation win to bank. Track which source pool carries each conclusion; if one origin dominates a load-bearing claim, flag it and seek an independent chain before printing the line as settled.

## Source pool
- **BD press:** Prothom Alo, The Daily Star, New Age, bdnews24, TBS, Bonik Barta.
- **BD primary:** Bangladesh Bank, BBS, Ministry of Finance, official gazette, Election Commission, ICT tribunal registry.
- **India read:** The Hindu, ThePrint, Indian Express, MEA statements.
- **China read:** SCMP, Global Times (treat as CN-state-signal, grade C-D: useful for what Beijing wants said, not for what happened).
- **US/West read:** Reuters, AP, State Department readouts, USTR notices.
- **Myanmar/Arakan:** The Irrawaddy, Myanmar Now.
- **Trade/finance:** Textile Today, apparel-trade press, shipping/maritime trackers.

Never treat a single one of these as sufficient alone for a load-bearing claim.
