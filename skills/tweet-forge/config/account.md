# Account config (template)

Fill this in once. The skill never posts without your explicit yes.

- **Handle:** YOUR_HANDLE (e.g. @example)
- **Timezone:** YOUR_TIMEZONE (e.g. Asia/Dhaka, UTC+6)
- **Posting cadence:** e.g. twice daily, morning and evening
- **Posting log:** path to the file or note where you record used topics,
  so the skill can avoid repeating a topic within seven days
  (e.g. `~/notes/x-posting-log.md`)
- **Active research threads:** list threads whose figures must stay
  consistent across drafts (papers, briefs, dashboards)
